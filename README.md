# biggs fitness

Biggs Fitness is a modern fitness and wellness platform built to help users stay consistent, track progress, and achieve their fitness goals through an intelligent and engaging digital experience.

The platform combines workout management, AI-powered generative fitness sessions, personalized plans based on selections, and progress analytics into one seamless ecosystem designed for both beginners and experienced fitness enthusiasts.

---

## Features

- Workout session management
- Fitness progress monitoring
- AI-powered generative fitness sessions
- Quick fitness suggestions
- Personalized workout plans
- Secure authentication with Google OAuth
- Responsive and modern user interface
- Payment integration with Paystack
- User dashboard and analytics
